# gas_price_brazil
Gasoline Prices in Brazil 🇧🇷⛽
This repository contains data and analysis on gasoline price trends in Brazil, based on a public dataset available on Kaggle.

📊 Data Source
The data used in this project comes from the Kaggle dataset "Preço dos Combustíveis no Brasil", which compiles information collected by ANP (Brazilian National Agency of Petroleum, Natural Gas and Biofuels) over the years.


🚀 Analysis Possibilities
Price trends by state and city

Comparison between regular and additive gasoline

Temporal patterns and impact of public policies

Price forecasting using statistical models

💡 Objective
To explore fuel consumption patterns and gasoline price variations in Brazil using public data, with a focus on clarity, accessibility, and insightful analysis.

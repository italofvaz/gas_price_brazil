# gas_price_brazil
Preço da Gasolina no Brasil 🇧🇷⛽
Este repositório contém dados e análises sobre a variação do preço da gasolina no Brasil, com base em um conjunto de dados público disponível na plataforma Kaggle.

📊 Fonte dos Dados
Os dados utilizados foram obtidos no Kaggle, no dataset "Preço dos Combustíveis no Brasil", que reúne informações coletadas pela ANP (Agência Nacional do Petróleo, Gás Natural e Biocombustíveis) ao longo dos anos.

📁 Conteúdo
data/: arquivos CSV com os dados brutos.

notebooks/: notebooks Jupyter com análises exploratórias e visualizações.

scripts/: scripts auxiliares de limpeza e transformação dos dados.

🚀 Possibilidades de Análise
Evolução do preço da gasolina por estado e cidade

Comparação entre gasolina comum e aditivada

Tendências temporais e impacto de políticas públicas

Previsões de preços com modelos estatísticos

💡 Objetivo
Explorar padrões de consumo e variação de preços dos combustíveis no Brasil, com foco na gasolina, a partir de dados públicos, de forma acessível e transparente.
